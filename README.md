# Diário de Biodiversidade Urbana

Meu primeiro projeto em Python voltado para uma área que eu gosto: Biologia.

A ideia é simples: criar um pequeno diário onde posso registrar animais e outras espécies que encontro em ambientes urbanos.

## O que o programa faz?

- Adicionar uma nova observação
- Ver as observações registradas
- Apagar uma observação
- Salvar os registros em um arquivo CSV

Cada registro possui:

- Espécie
- Bairro
- Data
- Observação

## O que usei

- Python
- CSV
- `os`
- Funções
- Condicionais
- Estruturas de repetição
- Tratamento de erros
- Leitura e escrita de arquivos

Não foram utilizadas bibliotecas externas.

## Como executar

Com o Python instalado, execute:

```bash
python main.py

Depois é só escolher uma das opções do menu.
